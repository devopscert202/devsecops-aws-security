# Course-End Project 02

## Overview

This project assesses your ability to apply DevSecOps principles and AWS security best practices learned throughout the course.

## Deliverables

- Configured CI/CD pipeline with integrated security scanning
- Documented threat model using STRIDE or PASTA
- AWS infrastructure with security best practices applied
- Vulnerability assessment report

## Skills Assessed

- Threat modeling (STRIDE, DREAD, PASTA)
- Pipeline security (SAST, DAST, SCA)
- AWS security services configuration
- IAM best practices
- EKS security

The detailed problem statement will be provided by your instructor (for example, as a PDF or other document distributed with the course).
